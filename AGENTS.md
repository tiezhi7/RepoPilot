
# RepoPilot Agent Instructions

## Project goal
Build a reliable AI-assisted code review platform.

## Learner profile
The developer is a beginner in software engineering.
Explain unfamiliar concepts, commands, files, and errors
in simple Chinese.

## Day 1 scope
- Only implement a Python FastAPI backend.
- Review Python source code using AST.
- Do not add a frontend, database, GitHub integration,
  or paid AI API yet.

## Engineering rules
- Make small, focused changes.
- Explain which files will change before editing.
- Do not execute user-submitted source code.
- Add automated tests for new functionality.
- Do not invent test results.
- Never commit secrets, tokens, or .env files.
- Keep code readable with useful comments.
- Do not add unnecessary dependencies.

## Before finishing a task
1. Explain what changed.
2. Run relevant tests when possible.
3. Report failures and limitations.
4. Suggest one next step.
